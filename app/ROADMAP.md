# SmartBiz — Product Roadmap & Future Phases

This document details the planned feature additions for post-MVP releases of SmartBiz.

---

## 🎯 MVP Release Status (Current)
- [x] Complete Offline Business Management Engine
- [x] Billing, Invoicing & Thermal/PDF Printing
- [x] Product Catalog, Stock Alerting & Pricing
- [x] Customer Credit Ledgers & Supplier Accounts
- [x] Cash Book, Expenses & Income Tracking
- [x] Multi-Domain Global Search Engine
- [x] Analytics Dashboard & Profit & Loss Reports
- [x] Database Backup & CSV Export
- [x] Material 3 UI with Adaptive Dark/Light Themes

---

## 🚀 Post-MVP Roadmap

### Phase 2: User Authentication & Multi-User Access Control
- Biometric PIN / Fingerprint lock for application access.
- Role-based access control (Owner, Cashier, Inventory Manager).
- Action audit logging for multi-staff stores.

### Phase 3: Cloud Synchronization & Multi-Device Backup
- Optional Google Drive auto-sync for database backups.
- Real-time multi-device database sync via encrypted P2P or Cloud backend.

### Phase 4: Hardware Peripheral Integrations
- Bluetooth thermal printer SDK direct integration.
- Camera barcode scanning with Zebra / Honeywell hardware barcode scanner support.

### Phase 5: Smart Financial AI Insights (Post-MVP)
- AI-driven inventory demand forecasting.
- Automated payment reminder templates for overdue customer ledgers.
